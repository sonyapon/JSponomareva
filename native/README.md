# HTML:
## 1. Про accessibility:
В начале файла есть `<html lang="ru">`, чтобы скринридер выбрал русский язык для произношения
Сделан класс `.visually-hidden`, который делает текстневидимым на экране, но при этом его читает скринридер
В секции используется `aria-labelledb`y  - это читается скринридером как "вход,область"
aria-hidden скрывает "или" от скринридера, потому что не несет смысловой нагрузки
Кнопки входа через сервисы сгруппированы через `role="group"` и `aria-label`.

## 2. Подход к верстке:
Выбран Flexbox, потому что большинство элементов распложены по вертикали в столбик. `flex:1` у main занимает все своюоное место на экране. у нас есть `body`, `main`, которые используют `display: flex;` для расположения объектов в вертикальный столбец по прорядку.
grid - не подходит, потому что у нас не используется двумерная сетка

# CSS:
Сделана адаптация под размер телефона. Вроде как в среднем 320px - расширение у телефонов. Поэтому в @media это число указано, как макс. ширина. И еще изменен отступ от границ самого экрана уменьшен с 29 px до 10 px.
